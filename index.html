Virtual machines
on stock iOS.

SideRoot is a static front-door for SideBoot (our own bootstrapper for SideOS virtual machines) and SideGrab (personal signing certificates). No jailbreak required on your real iPhone — everything runs as web-clips + signed VM images.

We use our own bootstrapper called SideBoot.

＋ Install SideBoot ＋ Install SideGrab ⤓ Install Archives

How install works (iOS Web-Clip):
1) Tap install → downloads a .mobileconfig profile.
2) iPhone Settings → Profile Downloaded → Install.
3) A bookmark appears on your Home Screen (SideBoot / SideGrab). Open it like an app — it runs fullscreen.

SideBoot

Welcome → Continue → + top-right → Sign setup (.p12 / .c12) → Boot menu (spam VOL−) → Install environment (.zip) → Boot SideOS fullscreen.

SideGrab

SideID login → Dashboard → Personal certificate (3-hour countdown + expiry) → Export .p12 → import into SideBoot.

Archives — SideOS images

Download a .zip with a SideOS image, then in SideBoot → Boot → Install environment pick the zip with the real iOS file picker. Each zip is a custom SideOS project for that version (newer versions unlock more apps/features).

KorBrowser (inside every SideOS) ships these sites: jailbreak.com · tweaksrepo.com · trollstore.com · coruna.net · aiprompt.txt

Create SideID

Used by SideGrab login. Saved to MongoDB when the API server is running, otherwise kept on-device (demo fallback).

API: POST /api/sideid {sideId,password} · GET /api/sideid (see server.js + MongoDB).
