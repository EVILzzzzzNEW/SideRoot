Archives — SideOS images 6 builds

Download a .zip with a SideOS image, then in SideBoot → Boot → Install environment pick the zip with the real iOS file picker. Each zip is a custom SideOS project for that version (newer versions unlock more apps/features).

KorBrowser (inside every SideOS) ships these sites: jailbreak.com · tweaksrepo.com · trollstore.com · coruna.net · aiprompt.txt

SideID + certificate (.c12)

Create an ID, then download your personal certificate directly as a .c12 file — no profile to install. Saved to MongoDB when the API server is running, otherwise kept on-device (demo fallback).

Want the dashboard with 3-hour countdown + re-export? Open the optional SideGrab bookmark and sign in. API: POST /api/sideid {sideId,password} (see server.js + MongoDB).
